Momarchy

Momarchy on pieni avoimen lähdekoodin sivuprojekti: tarkoitus on tehdä vanhasta läppäristä tarpeeksi yksinkertainen, että äitinikin voi käyttää sitä.

Pohjana on Omarchy. Momarchy Home yrittää piilottaa suurimman osan tietokonejutuista muutaman selvän valinnan taakse.

Erittäin varhaisessa kehitysvaiheessa — tämä muuttuu vielä nopeasti.

Momarchy on tällä hetkellä suunnattu suomalaiselle käyttäjälle. Lokalisointituki saattaa tulla myöhemmin. Ei lupauksia.

GitHub README Omarchy-pikaohje (PDF)

English

Momarchy is a small open-source side project: make an old laptop simple enough that even my mom can use it.

It is built on Omarchy. Momarchy Home tries to hide most of the computer-y parts behind a few obvious choices.

Very early development — expect things to change quickly.

Momarchy is currently aimed at a Finnish audience. Localization support might come later. No promises.
